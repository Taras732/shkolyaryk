Школярик

Освітньо-ігровий застосунок для дітей 3–8 років — навчання через гру.

⭐ Активний · Option A SLIM (family-only) Тип: Web-застосунок (PWA) Папка: D:/Dev/shkolyaryk Репо: Taras732/shkolyaryk Live: shkolyaryk.kuznya.studio Оновлено: 2026-06-20

1Концепція

Дитячий навчальний застосунок: набір міні-ігор (математика, мова, наука) для дошкільнят і молодших школярів 3–8 років. Навчання через гру — острови/хаб з ~36 інтерактивними іграми, батьківський дашборд зі статистикою прогресу. Поточна ціль — Option A SLIM: family-only реліз для 4 доньок Тараса + дружини як валідаційний пілот.

2Функціонал

  • Хаб з островами/іграми (~36 навчальних міні-ігор)
  • Онбординг + вибір ролі (дитина / батько) + профілі дітей
  • Батьківський дашборд: статистика та прогрес
  • Supabase Auth (email/пароль) + dev-login без бекенду
  • PWA: офлайн-доступ, встановлення на пристрій (vite-plugin-pwa)
  • Анти-монотонність: процедурна генерація завдань із варіативністю контенту

3Стек / Архітектура

Технології
Vite 5 + React 18 + TypeScript (web-збірка). Роутинг — react-router-dom 6, стан — Zustand, бекенд — Supabase, ефекти — canvas-confetti, іконки — lucide-react. PWA через vite-plugin-pwa.
Примітка: нативна версія — Expo SDK 54 / React Native (див. CLAUDE.md); цей каталог містить веб-збірку для GH Pages.
Ключові папки/файли
src/pages/ (Hub, GamePlayer, Auth, Onboarding, ParentDashboard, RoleSelect, Welcome), src/components/, src/stores/, src/utils/, vite.config.ts, index.html, supabase/, dist/ (білд)
Залежності/сервіси
Supabase (Auth + БД), GitHub Pages (хостинг web). BMAD workflow (.bmad/stories/, /sm /dev /qa)

4Запуск / Деплой

npm install # перший раз npm run dev # dev-сервер Vite (localhost:5173) npm run build # tsc + vite build → dist/ npm run preview # локальний перегляд білду npm run lint # ESLint

Деплой: статичний білд dist/ → GitHub Pages, домен shkolyaryk.kuznya.studio. Нативні збірки (iOS/Android) — через EAS Build/Update (хмарні, працюють з Windows).

6Приватність / Секрети

Секрети у .env (у .gitignore): ключі Supabase — EXPO_PUBLIC_SUPABASE_URL / EXPO_PUBLIC_SUPABASE_ANON_KEY (нативно) та відповідні VITE_*/публічні ключі у web. Шаблон — .env.example. Значення тут не наводяться. Дані дітей (профілі, прогрес) — у Supabase; family-only режим мінімізує PII.
⚠️ Шляхова залежність: цей каталог використовується як Docker mount / cron на node-auto — папку не переміщати й не перейменовувати.
